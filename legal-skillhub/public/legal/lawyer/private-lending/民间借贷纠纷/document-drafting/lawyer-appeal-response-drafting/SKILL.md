# 目标

根据被上诉人律师掌握的提示、草稿、对方上诉状、一审裁判信息和案件上下文，辅助生成可供继续编辑确认的民间借贷纠纷《民事上诉答辩状》正文。

本 Skill 只规定文书内容、结构和质量要求。最终确认、保存结果文件和导出 PDF 由后端流程处理，不要在正文中写工具调用、PDF 路径、导出说明或完成提示。

# 民间借贷上诉答辩要点

答辩意见必须针对上诉人的上诉请求和理由逐项回应，优先采用以下立场，只采用案件中确有依据的：

1. 一审事实认定清楚：本金、已还款金额、交付事实、利率约定的认定有在案证据支持的，主张应予维持。
2. 一审法律适用正确：利率上限、时效、保证、抵销等规则的适用符合民间借贷司法解释的，主张应予维持。
3. 上诉理由无新证据：上诉人未提交新证据、仅重复一审意见的，指出其主张缺乏事实基础。
4. 程序合法：一审程序无不当的，明确反驳程序类上诉理由。

# 借贷事实槽位

答辩意见中凡涉及借贷事实，写成可核对的明确表述（金额用阿拉伯数字）：

- 本金：一审认定的本金金额及依据。
- 已还：上诉人已还金额与时间（如实表述，不隐瞒）。
- 利率：约定利率及 LPR 四倍上限适用是否正确。
- 证据：己方证据名称、来源与证明目的；对上诉人新证据的质证意见。
- 保证：保证关系与保证责任。
- 抵销：有无可抵销的互负债务。
- 时效：借款到期日、催收经过与时效状态。

信息缺失时写"待补充"，不要虚构。

# 生成规则

1. 只输出完整《民事上诉答辩状》正文，不输出解释、摘要、Markdown 标题、代码块或操作说明。
2. 以玩家提示、玩家草稿和对方上诉状为主要意图来源；一审裁判信息用于核对认定结论。
3. 不要编造事实、证据、金额、日期、地址、身份证号或主体信息。
4. 答辩意见与上诉理由逐项对应，不遗漏主要上诉点；上诉理由明显无据的，明确指出。
5. 主张维持原判的，写明维持的具体判项。

# 文书模板

正文必须按下列模板组织：

```text
                    民事上诉答辩状

答辩人（自然人）：XXX，男/女，XXXX年XX月XX日生，X族，住XXXXXX。
答辩人（法人）：XXX，法定代表人：XXX，住所：XXXXXX。

答辩人因上诉人XXX提起的上诉一案，提出答辩如下：
......（逐项回应上诉请求与理由）

证据和证据来源，证人证言等：
1. 证据名称、来源及证明目的。
...

此致
[二审法院名称]
```

# 质量检查

输出前检查：

- 标题是否为"民事上诉答辩状"。
- 答辩人、答辩意见、证据、二审法院是否齐全。
- 是否逐项回应了上诉请求与理由。
- 涉金额表述是否为阿拉伯数字且来自案件信息。
- 是否误写了工具调用、PDF、文件路径、后台导出或"起草结束"等流程性内容。
