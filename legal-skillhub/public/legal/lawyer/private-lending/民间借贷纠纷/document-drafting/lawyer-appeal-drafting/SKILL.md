# 目标

根据上诉人律师掌握的提示、草稿、一审裁判信息和案件上下文，辅助生成可供继续编辑确认的民间借贷纠纷《民事上诉状》正文。

本 Skill 只规定文书内容、结构和质量要求。最终确认、保存结果文件和导出 PDF 由后端流程处理，不要在正文中写工具调用、PDF 路径、导出说明或完成提示。

# 民间借贷上诉理由

上诉请求和事实理由必须针对一审裁判的认定逐项展开，优先核查以下方向，只采用案件中确有依据的方向：

1. 事实认定错误：一审认定的本金、已还款金额、交付事实或利率约定与在案证据不符的，逐项指出并引用证据。
2. 法律适用错误：一审适用利率上限、时效、保证或抵销规则错误的，写明正确规则及依据。
3. 程序问题：一审遗漏必要共同诉讼人、应受理反诉未受理等程序瑕疵影响实体权利的。
4. 举证责任分配错误：一审对款项交付、借贷合意等要件事实的举证责任分配不当的。

# 借贷事实槽位

上诉状中凡涉及借贷事实，写成可核对的明确表述（金额用阿拉伯数字）：

- 本金：主张正确的本金金额及依据。
- 已还：一审认定或遗漏的还款金额与时间。
- 利率：正确的利率约定及 LPR 四倍上限依据。
- 证据：二审提交的新证据名称、来源与证明目的（无新证据则写明依据一审已有证据）。
- 保证：保证关系与保证责任认定是否正确。
- 抵销：一审未处理的抵销抗辩。
- 时效：一审时效认定是否错误。

信息缺失时写"待补充"，不要虚构。

# 生成规则

1. 只输出完整《民事上诉状》正文，不输出解释、摘要、Markdown 标题、代码块或操作说明。
2. 以玩家提示和玩家草稿为主要意图来源；一审裁判信息只用于核对认定结论。
3. 不要编造事实、证据、金额、日期、地址、身份证号或主体信息。
4. 上诉请求必须具体：撤销或变更一审判决的具体项（本金、利息、责任承担等），逐项列明。
5. 事实和理由围绕一审错误展开，不要复述一审卷宗全部内容。

# 文书模板

正文必须按下列模板组织：

```text
                    民事上诉状

上诉人（自然人）：XXX，男/女，XXXX年XX月XX日生，X族，住XXXXXX。
上诉人（法人）：XXX，法定代表人：XXX，住所：XXXXXX。

被上诉人（自然人）：XXX，男/女，XXXX年XX月XX日生，X族，住XXXXXX。
被上诉人（法人）：XXX，法定代表人：XXX，住所：XXXXXX。

上诉人因与被上诉人（案由）一案，不服XXXX人民法院（XXXX）...民初...号民事判决，现提起上诉。

上诉请求：
1. 撤销原判第X项，改判为……；
2. 本案一、二审诉讼费用由被上诉人负担。

事实和理由：
（针对一审认定逐项展开，写明正确的事实、证据与法律适用。）

证据和证据来源，证人证言等：
1. 证据名称、来源及证明目的。
...

此致
[二审法院名称]
```

# 质量检查

输出前检查：

- 标题是否为"民事上诉状"。
- 上诉人、被上诉人、上诉请求、事实和理由、证据、二审法院是否齐全。
- 上诉请求是否与一审裁判的具体判项对应。
- 涉金额表述是否为阿拉伯数字且来自案件信息。
- 利率、时效、保证等法律适用主张是否符合民间借贷规则。
- 是否误写了工具调用、PDF、文件路径、后台导出或"起草结束"等流程性内容。
