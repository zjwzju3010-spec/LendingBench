# 目标

根据原告律师掌握的提示、草稿和案件上下文，辅助生成可供继续编辑确认的民间借贷纠纷《民事起诉状》正文。

本 Skill 只规定文书内容、结构和质量要求。最终确认、保存结果文件和导出 PDF 由后端流程处理，不要在正文中写工具调用、PDF 路径、导出说明或完成提示。

# 民间借贷起诉的核心要件

1. 借贷合意与款项交付是民间借贷合同成立的两大要件，事实与理由部分必须分别交代：双方达成借款合意的时间、方式（口头/书面/借条），以及款项实际交付的金额、时间、方式（转账/现金/第三方代付）。
2. 主张本金时必须写明具体金额，且该金额必须来自案件已知信息，禁止编造或估算。
3. 主张利息时必须写明利率标准（年利率/月利率），并说明是否超过合同成立时一年期贷款市场报价利率（LPR）四倍上限；主张的利息总额不得突破该上限。
4. 若原告已经收到部分还款，事实与理由中必须如实写明已还金额与还款时间，不得隐瞒；已还款项依法按约定或法定顺序抵扣。
5. 起诉时应自查诉讼时效：自权利受损之日起超过三年且无中断、中止事由的，先评估时效风险再起草。

# 借贷事实槽位

正文应当把以下借贷事实写成可核对的明确表述（金额用阿拉伯数字，直接写进正文）：

- 本金：借出金额、交付时间与方式。
- 已还：被告已偿还金额（若无，写明"至今未偿还"）。
- 利率：约定的年利率/月利率及上限依据（LPR 四倍）。
- 证据：借条/欠条、银行转账记录、微信/支付宝转账凭证、现金交付的收条或证人等，逐项列出名称、来源与证明目的。
- 保证：有无保证人及保证方式（一般保证/连带保证）。
- 抵销：是否存在双方互负债务可抵销的情形。
- 时效：借款到期日或催收事实，说明起诉未超过诉讼时效。

信息缺失时，在对应位置写"待补充"，不要为完整而虚构。

# 生成规则

1. 只输出完整《民事起诉状》正文，不输出解释、摘要、Markdown 标题、代码块或操作说明。
2. 以玩家提示和玩家草稿为主要意图来源；案件上下文只用于补足事实、主体、诉求、证据和法院信息。
3. 不要编造事实、证据、金额、日期、地址、身份证号或主体信息。
4. 诉讼请求必须具体、可执行：本金、利息（注明起算日与利率）、逾期利息、诉讼费用负担，逐项列明并与事实和理由对应。
5. 证据部分只列已经从提示、草稿或上下文中出现的证据。
6. 如果玩家草稿已有明确表达，优先保留其核心诉求和事实逻辑，只做结构化、法律化和格式化整理。

# 文书模板

正文必须按下列模板组织：

```text
                    民事起诉状

原告（自然人）：XXX，男/女，XXXX年XX月XX日生，X族，住XXXXXX。
原告（法人）：XXX，法定代表人：XXX，住所：XXXXXX。

被告（自然人）：XXX，男/女，XXXX年XX月XX日生，X族，住XXXXXX。
被告（法人）：XXX，法定代表人：XXX，住所：XXXXXX。

诉讼请求：
1. 判令被告偿还借款本金人民币XX元；
2. 判令被告支付利息（自XXXX年XX月XX日起至实际清偿之日止，按年利率X%计算，以不超过一年期LPR四倍为限）；
3. 本案诉讼费用由被告负担。

事实和理由：
（写明借贷合意、款项交付、约定利率、已还金额、催收与时效经过。）

证据和证据来源，证人证言等：
1. 证据名称、来源及证明目的。
...

此致
[受诉法院名称]
```

# 质量检查

输出前检查：

- 标题是否为"民事起诉状"。
- 原告、被告、诉讼请求、事实和理由、证据、受诉法院是否齐全。
- 本金金额是否为阿拉伯数字且来自案件信息；已还金额是否如实写明。
- 主张利率是否超过 LPR 四倍上限；利息计算是否说明起算日与利率。
- 借贷合意与款项交付两要件是否都有交代。
- 是否误写了工具调用、PDF、文件路径、后台导出或"起草结束"等流程性内容。
